# Bolsa de trabajo

## Auxiliar de Sistemas

**Almacenes CCR, S.A. de C.V.** busca Auxiliar de Sistemas para incorporarse a la sucursal Centro.

### Actividades

- Administración y soporte del sistema CCR-Bodegas v2.1 (plataforma web interna).
- Ejecución y verificación del respaldo diario de la base de datos, almacenado en el servidor de aplicaciones.
- Alta de clientes y actualización de precios en el sistema.
- Atención de usuarios de las tres sucursales: Centro, Industrial y Norte.
- Apoyo en la migración pendiente a la versión 3 del sistema, en coordinación con Sistemas Alarcón, S.C.

### Requisitos

- Estudios concluidos o en curso en Informática, Sistemas Computacionales o área afín.
- Experiencia comprobable con bases de datos SQLite o SQL en general.
- Conocimiento de Python y Flask, o disposición para aprenderlos (el sistema actual corre sobre esa plataforma).
- Disponibilidad para trasladarse a las sucursales Industrial y Norte cuando se requiera.
- Manejo de paquetería de oficina.

### Se ofrece

- Contrato por tiempo determinado con posibilidad de renovación.
- Prestaciones de ley.
- Horario de lunes a viernes de 9:00 a 18:00 horas.
- Capacitación en el sistema CCR-Bodegas por parte del proveedor.

### Postulación

Enviar solicitud con currículum a rhumanos@ccr-almacenes.example, indicando en el asunto "Auxiliar de Sistemas — 2022". El puesto reporta directamente a la Dirección de Administración.

Para dudas sobre el puesto puede escribir a soporte@ccr-almacenes.example.
